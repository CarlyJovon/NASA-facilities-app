# NASA Facilities Weather Dashboard 
A web application that displays NASA facilities across the United States along with their current weather conditions. The project combines NASA facility data with real-time weather information to provide a simple, accessible way to explore NASA locations and their surrounding weather.

## Features
- Displays NASA facilities and their locations
- Retrieves current weather conditions for each facility
- Displays temperature and weather descriptions
- Organizes facilities into a responsive card layout
- Provides a clean, user-friendly interface
- Uses CSS styling to improve readability and visual presentation

## Tech Stack 
- HTML
- CSS
- JavaScript
- NASA facility data
- WeatherAPI
  
## Getting Started
1. Clone the repository:
```
git clone https://github.com/CarlyJovon/NASA-facilities-app.git
```
2. Navigate to the project directory:
```
cd NASA-facilities-app
```
3. Open `index.html` in your browser or use a local development server.

Configure your WeatherAPI credentials if required.

## API Requirements
This application uses WeatherAPI to retrieve current weather conditions based on facility coordinates.
You'll need a WeatherAPI key to retrieve weather data.
Visit WeatherAPI to learn more and obtain an API key.
